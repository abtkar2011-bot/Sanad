# سند

منصة عُمانية مجانية للمساعدة المجتمعية: اطلب المساعدة أو قدّمها لمن حولك.

**الرابط:** https://abtkar2011-bot.github.io/Sanad/

## الأقسام

- **سند على الطريق:** توصيل الناس دون مقابل، ومساعدة من تعطّلت سيارته.
- **سند في الحياة الاجتماعية:** تنظيف الطرق والأفلاج والمبادرات الجماعية.
- **سند في الأفراح والأتراح:** المساعدة في الأعراس والعزاء.
- **سند لكبار السن:** واجهة بسيطة جدًا، وطلب المساعدة بضغطة أو برسالة صوتية.

الطلب الفوري يظهر لمن حولك في نطاق ١٠ كم، والطلب الذي له موعد يظهر لأهل الولاية.

## الملفات

| الملف | عمله |
| --- | --- |
| `index.html` | التطبيق كاملًا (مع خريطة الولايات الـ٦١). |
| `config.js` | رابط قاعدة البيانات ومفتاحها العام. إذا كان فارغًا يعمل الموقع بالأمثلة فقط. |
| `cloud.js` | الاتصال بقاعدة البيانات (Supabase). |
| `supabase.sql` | إعداد قاعدة البيانات، يُشغَّل مرة واحدة. |
| `manifest.webmanifest`، `sw.js`، `icons/` | لتثبيت سند على الجوال كتطبيق. |

## قاعدة البيانات

البيانات المشتركة في [Supabase](https://supabase.com). لتجهيزها مرة واحدة:
افتح المشروع ← **SQL Editor** ← **New query** ← الصق محتوى [`supabase.sql`](supabase.sql) ← **Run**.
ثم ضع **Project URL** و**Publishable key** في `config.js`.

البلاغات والحسابات تجدها في Supabase ← **Table Editor** ← `sanad_docs`.
